# AI Proof-of-Life (Google Vision)

This folder contains the output of a one-time Google Vision smoke test: `visionSmokeTest.json`.

- API: Label Detection (Google Cloud Vision)
- Run locally with a service account; **no credentials or images are committed**
- Usage was for the Sept 23 prototype demo to show AI readiness

Demo talking points:
- Vision API is enabled and reachable with our project credentials.
- The service returned label predictions for a car image, which we can later wire into the repair-estimation flow.
